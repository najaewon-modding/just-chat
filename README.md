# Just Chat

Minecraft의 기본 플레이어 채팅을 **서버 영구 기록 기반 채팅 시스템**으로 확장하는 NeoForge 모드입니다.

플레이어가 실제로 전달받은 채팅과 시스템 메시지를 서버 월드에 저장하고, 귓속말, 플레이어 태그, 아이템 태그, 읽음 상태, 메시지 삭제, 서버 측 필터 및 기록 탐색 기능을 제공합니다.

## 지원 환경

| 항목 | 값 |
| --- | --- |
| Minecraft | `26.1.2` |
| NeoForge | `26.1.2.97+` |
| Java | `25` |
| 언어 | 한국어 / English |
| 네트워크 프로토콜 | `7` |
| 멀티플레이 | 서버와 클라이언트 모두 설치 |

## 주요 기능

### 영구 메시지 기록

플레이어에게 실제로 전달된 `overlay=false` 채팅 및 시스템 메시지를 서버 월드에 영구 저장합니다.

- 전역 메시지는 모든 플레이어의 기록에서 확인할 수 있습니다.
- 특정 플레이어에게만 전달된 메시지는 해당 audience에 포함된 플레이어만 확인할 수 있습니다.
- `/tellraw @a`, `/tellraw <target>` 및 데이터팩에서 생성한 `tellraw` 메시지를 지원합니다.
- 발전 과제와 BlazeandCave's Advancements Pack 같은 데이터팩 메시지도 실제 수신자를 기준으로 저장합니다.
- Action Bar 등 `overlay=true` 메시지는 저장하지 않습니다.
- 명령어 오류와 `/tp`, `/give`, `/time` 등의 일반적인 명령 실행 피드백은 화면에는 표시되지만 영구 기록에는 저장하지 않습니다.
- 서버가 재시작되어도 이전 기록을 다시 불러올 수 있습니다.
- 플레이어가 오프라인인 동안 생성된 전역 메시지도 이후 기록에서 확인할 수 있습니다.
- 오래된 기록과 새로운 기록을 양방향으로 탐색할 수 있습니다.
- 대량의 기록은 segment 단위로 관리하며 별도의 보존 기간 제한을 두지 않습니다.

### 채팅 필터

Just Chat 화면 상단에서 서버 기록을 다음 기준으로 조회할 수 있습니다.

| 필터 | 표시 내용 |
| --- | --- |
| 모든 채팅 | 현재 플레이어가 볼 수 있는 전체 기록 |
| 전체 대상 | 모든 플레이어를 대상으로 한 전역 메시지 |
| 나에게만 | 귓속말을 제외하고 정확히 자신만 대상으로 한 메시지 |
| 귓속말 | 자신이 보내거나 받은 귓속말 |

필터링은 최근에 클라이언트로 내려온 메시지만 임시로 거르는 방식이 아니라 **서버 측 기록 조회와 페이지네이션**을 기준으로 동작합니다. Just Chat 화면을 새로 열면 기본 필터는 항상 `모든 채팅`입니다.

### 귓속말

입력창의 대상 선택 메뉴에서 `전체에게` 또는 현재 온라인 플레이어를 선택할 수 있습니다.

- 귓속말은 발신자와 수신자에게만 저장됩니다.
- 받은 귓속말을 클릭하면 해당 발신자를 바로 답장 대상으로 선택할 수 있습니다.
- 선택한 상대가 전송 전에 오프라인이 되면 메시지는 전송하거나 저장하지 않고 대상을 `전체에게`로 되돌립니다.
- 긴 플레이어 이름은 대상 메뉴에서 hover 시 가로 marquee 방식으로 확인할 수 있습니다.

### 메시지 메타데이터

서버에 저장되는 영구 메시지는 본문뿐 아니라 메시지의 전달 맥락도 함께 기록합니다.

- `sender`: 발신자 정보
- `audience`: 전역 또는 특정 플레이어 집합
- `origin`: player chat, vanilla broadcast, tellraw, direct system message, whisper 등 메시지 출처

이 정보를 이용해 같은 시스템 메시지라도 실제 수신 범위와 출처에 맞게 기록하고 조회합니다.

### 전용 채팅 화면

`T` 키를 누르면 Minecraft 기본 채팅 대신 Just Chat 화면을 엽니다. `/` 키는 기존 Minecraft 명령어 입력 화면을 사용하여 일반 채팅과 명령 입력을 분리합니다.

- 과거 기록을 보고 있을 때 새 메시지가 도착하면 새 메시지 알림 표시
- `↓` 버튼으로 최신 메시지로 즉시 이동
- 플레이어 메시지를 `<PlayerName> 메시지` 형식으로 표시
- Just Chat 화면이 열려 있는 동안 vanilla chat HUD만 숨기고 vanilla history 자체는 유지
- 배경 blur 없이 화면 dim 효과만 사용
- 플레이어 이름 hover 시 클릭 가능한 커서 표시

### 플레이어 태그

`@PlayerName` 형식으로 다른 플레이어를 태그할 수 있습니다.

- 온라인 플레이어를 우선 추천합니다.
- 이전에 알려진 오프라인 플레이어도 추천 대상에 포함할 수 있습니다.
- 태그된 플레이어에게 mention 알림을 표시합니다.
- 플레이어의 온라인 상태와 마지막 접속 시간을 확인할 수 있습니다.

### 아이템 태그

현재 인벤토리의 아이템을 채팅 메시지에 삽입할 수 있습니다.

- 서버가 실제 아이템 스냅샷을 기준으로 태그를 검증합니다.
- 아이템 이름과 hover 정보를 채팅에서 확인할 수 있습니다.
- 클라이언트가 임의의 아이템 정보를 만들어 전송하는 방식이 아닙니다.

### 메시지 삭제

자신이 보낸 메시지는 전송 후 **5분 이내**에 삭제할 수 있습니다.

삭제 시 서버 기록 자체를 완전히 제거하는 대신 원문과 태그 정보를 제거하고, 해당 위치에는 회색 삭제 안내 메시지를 남깁니다.

### 읽음 상태

플레이어별 마지막 읽은 메시지 위치를 서버에 저장합니다.

- 읽지 않은 메시지가 있으면 읽음 경계를 표시합니다.
- 재접속 후에도 읽음 상태를 이어서 사용할 수 있습니다.
- 읽음 경계와 read-through 갱신은 기본 `모든 채팅` 보기를 기준으로 처리합니다.

### 클라이언트 설정

현재 제공되는 설정:

| 설정 | 기본값 | 설명 |
| --- | --- | --- |
| Close chat after sending | `false` | 메시지를 전송한 뒤 채팅 화면을 자동으로 닫을지 설정합니다. |

### 서버 측 보호

클라이언트 요청을 그대로 신뢰하지 않고 서버 측에서 여러 보호 장치를 적용합니다.

- 채팅 전송 rate limit
- 메시지 삭제 rate limit 및 권한 검증
- history 요청 rate limit
- 플레이어 추천 및 상태 조회 rate limit
- history 요청별 request ID 사용
- timeout 이후 늦게 도착한 오래된 응답 무시
- 초기 history 요청 timeout 시 안전한 재요청

## 설치

1. Minecraft `26.1.2`와 NeoForge `26.1.2.97` 이상을 설치합니다.
2. Just Chat JAR 파일을 클라이언트의 `mods` 폴더에 넣습니다.
3. 멀티플레이 서버에서는 서버의 `mods` 폴더에도 **동일한 버전**의 JAR 파일을 넣습니다.
4. Minecraft와 서버를 실행합니다.

GitHub Releases를 사용하는 경우 자동 생성되는 `Source code (zip)` 또는 `Source code (tar.gz)`가 아니라 **Assets에 첨부된 JAR 파일**을 사용해야 합니다.

## 사용 방법

### 일반 채팅

```text
T       Just Chat 열기
Enter   메시지 전송
/       Minecraft 명령어 입력
```

Just Chat 입력창에서는 `/`로 시작하는 내용을 일반 채팅으로 전송하지 않습니다.

일반 플레이어 메시지는 다음과 같이 표시됩니다.

```text
<PlayerName> 안녕하세요!
```

### 귓속말

입력창 왼쪽 대상 선택 메뉴에서 온라인 플레이어를 선택한 뒤 메시지를 전송합니다. 받은 귓속말을 클릭하면 해당 플레이어를 답장 대상으로 바로 선택할 수 있습니다.

### 플레이어 태그

채팅 입력 중 `@` 뒤에 플레이어 이름을 입력하면 추천 목록이 표시됩니다.

```text
@PlayerName 안녕하세요!
```

### 아이템 태그

Just Chat 화면의 아이템 버튼을 눌러 현재 인벤토리의 아이템을 메시지에 삽입할 수 있습니다. 실제 아이템 정보는 서버 검증 후 메시지에 포함됩니다.

## 멀티플레이 및 데이터 저장

Just Chat의 영구 메시지 기록 기능은 서버가 기준입니다. 따라서 멀티플레이에서는 서버와 클라이언트 모두에 Just Chat을 설치하고 같은 버전을 사용하는 것을 권장합니다.

메시지 기록은 단순한 클라이언트 채팅 로그가 아니라 서버 월드 데이터로 관리되며, 각 플레이어가 실제로 볼 수 있었던 audience 정보를 기준으로 조회 권한을 유지합니다.

## 기술 정보

- 모드 ID: `njw_just_chat`
- 네트워크 프로토콜: `7`
- 저장 대상: `overlay=false`의 지원되는 채팅/시스템 메시지
- 비저장 대상: Action Bar와 일반 명령 실행 피드백/오류
- 기록 조회: 서버 측 필터 + 페이지네이션
- 메시지 접근 범위: 저장된 audience 기준
