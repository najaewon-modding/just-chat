# Just Chat

A persistent, feature-rich chat system that replaces Minecraft's default player chat.

## Features

- Custom chat interface
- Open chat with `Enter` or `Ctrl + T`
- Persistent server-side chat history
- View messages sent while you were offline
- Delete your own messages within 5 minutes
- Player tagging with `@`
- Item tagging
- Vanilla chat reserved for commands

## Development Environment

- Minecraft 26.1.2
- NeoForge
- Java
- Mixin support enabled

## Status

Just Chat is currently in early development.
