# Just Chat

Minecraft의 기본 플레이어 채팅을 확장하여 **영구 채팅 기록**, 귓속말, 플레이어 태그, 아이템 태그, 읽음 상태, 메시지 삭제 기능을 제공하는 NeoForge 모드입니다.

서버가 재시작되어도 이전 채팅 기록을 다시 확인할 수 있으며, 일반 플레이어 채팅뿐 아니라 서버 메시지와 데이터팩 메시지도 함께 관리할 수 있습니다.

## 지원 환경

| 항목 | 값 |
| --- | --- |
| Minecraft | `26.1.2` |
| NeoForge | `26.1.2.97+` |
| Java | `25` |
| 언어 | 한국어 / English |
| 멀티플레이 | 서버와 클라이언트 모두 설치 |

## 주요 기능

### 영구 채팅 기록

플레이어가 실제로 받은 채팅과 시스템 메시지를 서버에 저장하고 나중에 다시 확인할 수 있습니다.

- 서버 재시작 후에도 이전 기록 유지
- 오래된 기록과 최신 기록 탐색
- 전역 메시지와 개인 대상 메시지를 구분하여 표시
- `/tellraw`로 전송된 메시지 지원
- 발전 과제 및 BlazeandCave's Advancements Pack 같은 데이터팩 메시지 지원
- 플레이어가 오프라인이었던 동안 발생한 전역 메시지도 이후 확인 가능

Action Bar 메시지는 기록하지 않습니다. 또한 `/tp`, `/give`, `/time` 등의 일반적인 명령어 실행 결과와 명령어 오류 메시지는 화면에는 표시되지만 영구 채팅 기록에는 남기지 않습니다.

### 채팅 필터

Just Chat 화면 상단에서 기록을 다음 기준으로 나누어 볼 수 있습니다.

| 필터 | 표시 내용 |
| --- | --- |
| 모든 채팅 | 현재 플레이어가 볼 수 있는 전체 기록 |
| 전체 대상 | 모든 플레이어에게 전송된 메시지 |
| 나에게만 | 자신에게만 전송된 메시지 |
| 귓속말 | 자신이 보내거나 받은 귓속말 |

Just Chat 화면을 새로 열면 기본 필터는 `모든 채팅`입니다.

### 귓속말

입력창 왼쪽의 대상 선택 메뉴에서 `전체에게` 또는 현재 온라인 플레이어를 선택할 수 있습니다.

- 귓속말은 발신자와 수신자만 볼 수 있습니다.
- 받은 귓속말을 클릭하면 해당 플레이어를 바로 답장 대상으로 선택할 수 있습니다.
- 선택한 상대가 전송 전에 오프라인이 되면 메시지는 전송되지 않습니다.

### 전용 채팅 화면

`T` 키를 누르면 Just Chat 화면을 엽니다. `/` 키는 기존 Minecraft 명령어 입력 화면을 사용합니다.

- 일반 채팅과 명령어 입력을 분리
- 과거 기록을 보고 있을 때 새 메시지 도착 알림 표시
- `↓` 버튼으로 최신 메시지로 이동
- 플레이어 메시지를 `<PlayerName> 메시지` 형식으로 표시

### 플레이어 태그

`@PlayerName` 형식으로 다른 플레이어를 태그할 수 있습니다.

- 입력 중 플레이어 이름 자동 추천
- 온라인 플레이어 우선 추천
- 이전에 접속한 플레이어도 추천 가능
- 태그된 플레이어에게 알림 표시
- 온라인 상태와 마지막 접속 시간 확인

### 아이템 태그

현재 인벤토리의 아이템을 채팅 메시지에 삽입할 수 있습니다.

아이템 이름과 상세 정보를 채팅에서 바로 확인할 수 있어 장비나 아이템 정보를 다른 플레이어와 쉽게 공유할 수 있습니다.

### 메시지 삭제

자신이 보낸 메시지는 전송 후 **5분 이내**에 삭제할 수 있습니다.

삭제된 메시지는 완전히 사라지는 대신 해당 위치에 삭제된 메시지라는 안내가 남습니다.

### 읽음 상태

플레이어별 읽음 상태를 저장합니다.

- 읽지 않은 메시지가 있으면 읽음 경계 표시
- 재접속 후에도 읽음 상태 유지
- 과거 기록을 확인한 뒤 다시 최신 메시지로 이동 가능

### 클라이언트 설정

현재 다음 설정을 제공합니다.

| 설정 | 기본값 | 설명 |
| --- | --- | --- |
| Close chat after sending | `false` | 메시지 전송 후 채팅 화면을 자동으로 닫을지 설정합니다. |

## 사용 방법

### 일반 채팅

```text
T       Just Chat 열기
Enter   메시지 전송
/       Minecraft 명령어 입력
```

일반 플레이어 메시지는 다음과 같이 표시됩니다.

```text
<PlayerName> 안녕하세요!
```

### 귓속말

입력창 왼쪽의 대상 선택 메뉴에서 온라인 플레이어를 선택한 뒤 메시지를 전송합니다. 받은 귓속말을 클릭하면 해당 플레이어를 답장 대상으로 바로 선택할 수 있습니다.

### 플레이어 태그

채팅 입력 중 `@` 뒤에 플레이어 이름을 입력하면 추천 목록이 표시됩니다.

```text
@PlayerName 안녕하세요!
```

### 아이템 태그

Just Chat 화면의 아이템 버튼을 눌러 현재 인벤토리의 아이템을 메시지에 삽입할 수 있습니다.

## 설치

1. Minecraft `26.1.2`와 NeoForge `26.1.2.97` 이상을 설치합니다.
2. Just Chat JAR 파일을 클라이언트의 `mods` 폴더에 넣습니다.
3. 멀티플레이 서버에서는 서버의 `mods` 폴더에도 동일한 버전의 JAR 파일을 넣습니다.
4. Minecraft와 서버를 실행합니다.

GitHub Releases를 사용하는 경우 자동 생성되는 `Source code` 압축 파일이 아니라 **Assets에 첨부된 JAR 파일**을 사용하세요.
