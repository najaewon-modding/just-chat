# Just Chat v1.1.1-mc26.1.2

Just Chat v1.1.1-mc26.1.2 is a small UI polish release for Minecraft 26.1.2.

## Compatibility

* Minecraft **26.1.2**
* NeoForge **26.1.2.97 or later**
* Just Chat **1.1.1-mc26.1.2**
* Java **25**
* Network protocol **7**

For multiplayer, install the same Just Chat version on both the client and the server.

## Changes

* Adjusted the vertical spacing between the `↓` jump-to-latest button and the item button from 4 px to **6 px**.
* Kept the jump button's existing right-aligned X position and all existing behavior unchanged.

## Installation

1. Install Minecraft **26.1.2** with NeoForge **26.1.2.97 or later**.
2. Download `njw_just_chat-1.1.1-mc26.1.2.jar` from the **Assets** section below.
3. Place the JAR in your client's `mods` folder.
4. For multiplayer servers, place the same JAR in the server's `mods` folder.
5. Start Minecraft.

> The automatically generated `Source code (zip)` and `Source code (tar.gz)` files are not the installable mod.
>
> Use `njw_just_chat-1.1.1-mc26.1.2.jar` from the Assets section.
